# LightReader — 轻量级 EPUB 阅读器

LightReader 是一个基于浏览器的轻量级 EPUB 电子书阅读器，提供简洁、优雅的阅读体验，支持「🧩浏览器插件」自由扩展。无需注册、无需上传，文件完全留在本地，打开即读。

**在线使用：<https://lynnete07.github.io/epub-reader/>**

## 功能

- 📖 拖放打开 EPUB，支持 EPUB 2 / 3 目录导航
- 🔖 自动保存阅读进度，刷新后接着读
- 🔤 正文字体切换与字号调节，支持填入本机已安装的字体（多字体按语言回退）
- 🌓 明暗双主题
- ⚡ 离线可用（PWA），可添加到主屏幕
- 🔍 章节内图片、样式与内嵌字体完整渲染
- 🧩 可通过浏览器插件自由扩展

## 隐私

LightReader 完全在浏览器本地运行：

- 你的 EPUB 文件**不会**上传到任何服务器，书籍与阅读进度仅存于浏览器本地存储
- 当前没有第三方访问统计；书名、正文、阅读位置等内容数据不会离开浏览器

## EPUB 内容安全边界

章节内容会在**不允许脚本执行**的沙箱 iframe 内显示；进入沙箱前，阅读器会移除脚本、事件属性、嵌入内容、危险 URL 和外部 CSS 资源，并用 CSP 阻断网络访问。书籍内容不能读取应用的 localStorage 或 IndexedDB，也不能覆盖应用界面。

这是一层面向不可信内容的防护，不代表任意文件都不会造成兼容性或性能问题。对于来源不明、异常巨大的 EPUB，仍建议谨慎打开；安全回归要求见 [`docs/TESTING.md`](docs/TESTING.md)。

## 技术栈

纯原生 JavaScript + JSZip，无框架、无构建依赖。纯静态部署，数据不出浏览器。
