# LightReader — 轻量级 EPUB 阅读器

基于浏览器的 EPUB 电子书阅读器。无需注册、无需上传，文件完全留在本地，打开即读。

**在线使用：<https://epub-reader-rust.vercel.app/>**

## 功能

- 📖 拖放打开 EPUB，支持 EPUB 2 / 3 目录导航
- 🔖 自动保存阅读进度，刷新后接着读
- 🔤 五档正文字体（无衬线 / 衬线 / 宋体 / 楷体 / 等宽）与字号调节
- 🌓 明暗双主题
- ⚡ 离线可用（PWA），可添加到主屏幕
- 🔍 章节内图片、样式与内嵌字体完整渲染
- 🧩 可通过浏览器插件自由扩展

## 隐私

LightReader 完全在浏览器本地运行：

- 你的 EPUB 文件**不会**上传到任何服务器，书籍与阅读进度仅存于浏览器本地存储
- 匿名访问统计无 Cookie、无指纹，不收集书名、正文、阅读位置等任何内容数据

## 技术栈

纯原生 JavaScript + JSZip，无框架、无构建依赖。纯静态部署，数据不出浏览器。
